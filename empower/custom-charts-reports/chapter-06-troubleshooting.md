# Chapter 6: Troubleshooting

*From TN-CustomChartsReports*

---

## Overview

Here are a few tips on troubleshooting if your report doesn't look quite right or doesn't show at all.

Typically, if you don't see your report in the report pane, it is because of a JavaScript error. To debug such errors, you will find the JavaScript console window in your browser helpful.

If you are having trouble isolating the source of an error, commenting out parts of your report file is an old programmer's trick.

## Using Show Raw Data

Particularly if the report is showing something but not exactly as you expected, using Empower's **Options > Show Raw Data** command can be very useful. This command opens another browser window and shows the traffic to and from the Empower server. This will show you your report in what we might call "partially digested" form:

- The placeholders will have been replaced by values from the database
- You will see the extra variable with its values filled in
- The JavaScript code will not have been executed yet

So you won't be looking at the final HTML form of your report.

## Viewing Final HTML Form

To see the final HTML form, follow these steps:

1. Run the report
2. Run the command **File > Export Report HTML**
3. Open the resulting HTML file
4. Use the appropriate command for your browser to view the page source

You will see the exact HTML of your report: the `<style>` section with the style definitions, and the `<body>` section with all the markup and data generated by your JavaScript code (which, having served its purpose, will not be in the report HTML).

The HTML source for your report will probably not be very reader-friendly, with most of it on one line. Cut the source and paste it into a HTML beautifier (there are many online tools to do this on the Web; one we like is at jsbeautifier.org). If you have misplaced an HTML tag or some such error, the error will usually be very easy to spot with beautified HTML.

## Testing with JSFiddle

Follow the steps below to set up a JSFiddle page for experimenting with custom charts and reports.

### Standard Charts and Reports

1. Navigate to https://jsfiddle.net
2. Click **External Resources**
3. Where you see **JavaScript/CSS URI**, enter:
   - `https://dev.encore-analytics.com/dev-empower/chrp-min.js`
   - Click **+**, then click the newly added link `chrp-min.js` (you should see the contents)
4. Repeat for:
   - `https://dev.encore-analytics.com/dev-empower/report-min.css`
   - `https://code.highcharts.com/highcharts.js`
   - Verify the links
5. In the top left pane, enter:
   ```html
   <div id="container"></div>
   ```
6. In the bottom left pane, enter:
   ```javascript
   if(0) {
     Highcharts.chart("container", options);
   } else if (args.type === "chart") {
     Highcharts.chart("container", test());
   } else {
     document.getElementById("container").innerHTML = test();
   }
   ```
7. In Empower, open the **Options > Show Raw Data** window, then the BAC by CAM custom chart
8. Copy the entire line beginning `var extra =` from the raw data window and paste it into the bottom left pane of the jsfiddle page, above the code block you just entered
9. Convert the anonymous function to a named function, `test`:
   - At the beginning of the anonymous function, change `(function()` to `function test()`
   - At the end of the anonymous function, delete the trailing parenthesis and semicolon `);`
10. Click the **Run** toolbar button. The chart should display. If it does not, open the debug console and look for errors
11. Save the fiddle and bookmark it for future use

### AT-Style Charts

The procedure for AT charts is slightly different:

1. In Empower, open the **Options > Show Raw Data** window, then the Who Charged custom chart
2. Copy the entire line beginning with `{` from the raw data window and paste it into the bottom left pane of the jsfiddle page (replace any existing code, except the code block at the bottom)
3. Click **Tidy** (note the absence of an anonymous function; this is the defining characteristic of AT-style charts and reports)
4. At the top of the page, enter `var options =` in front of the opening brace `{`
5. Change `if(0)` to `if(1)` in the first line of the code block at bottom
6. (Optional) Enter a semicolon after the closing brace `}`
7. Click **Run**. The chart should display
