# 16.12 Copy Forward

The Copy Forward command, as its name suggests, allows the user to copy certain information about a contract from one period to a later period. Selecting Copy Forward from the Admin menu brings up the dialog shown in Figure 16.118. The first step is to select the contract, the period from which the data is to be copied (the from period), and the period to which the data will be copied (the to period). Next, the user selects which items are to be copied to the to period, using the checkboxes shown in the figure.

**Figure 16.118: Copy Forward, Step 1**

Then user clicks Submit, and sees a status message like that of Figure 16.119. Note that Empower identifies the to and from period, as well as the types of data copied forward.
