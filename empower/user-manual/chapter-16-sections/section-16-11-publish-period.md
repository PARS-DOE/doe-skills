## 16.11 Publish Period

The Publish Period command allows the user to set the PubLevel of the most recent period of the selected contracts. Multiple contracts can be selected at once.

**Figure 16.116: Publish Period**

To set the PubLevel, select the contract(s) that you want to publish, enter the desired "PubLevel" in the input box, then click OK. To filter to contracts that have a specific PubLevel, click "Filter" and enter the PubLevel that you want to filter to in the pop-up.

**Figure 16.117: Publish Period Filter**

To undo any applied filters use a blank filter. Note that only users with "Write" permissions can publish periods.
