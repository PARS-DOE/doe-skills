## Key Implementation Areas

### Server setup
- Install Empower Software
- Initialize Database (Microsoft SQL Server or Oracle)
- Configure Data Source

### Software rollout
- Identify Users and Roles
- Determine login method (App, SSO, AD, ADFS, SAML)
- Configure login method
- Configure alternate menus for Roles/User Code
- Configure email notification
- Configure WatchDir

### Load Data
- Configure Cost Export from EVM Engine
- Configure Schedule Export from IMS tool
- Configure WAD export from WAD tool

### Monthly Data
- Monthly performance data (including period header data)
- Contract data
- Populate contract level DQI setting (e.g., ID LOE, 50/50, 0/100, etc. IDs for EVM and IMS data)
- Populate VAR Reporting Thresholds
- Populate calendar
- Mark EOCs

### VAR and Corrective Action
- Populate submit/review/approve
- Verify data and make corrections
- Configure Reporting levels

### Reporting Configuration
- IPMR Report/Format 5
- EDI (IPMR XML, Empower optimized, etc.)
- Review and configure DQIs and data-driven audit test sheets

### Dashboard Setup
- Build initial global views, filters and dashboards
- Build initial views, filters and dashboards for User Code

### Final Steps
- Populate users and attributes
- Train users
- Identify opportunities for custom reports, charts, fields & DQIs
- Document monthly business rhythm with desktop procedure
